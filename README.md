# Restaurant Platform

This project is a full-stack restaurant platform.

## Features
- User registration
- User login
- Restaurant management
- View restaurants
- Search restaurants
- Add restaurant images
- Menu management
- Booking system
- Ratings
- Comments
- Pagination

## Technologies Used
- React
- Node.js
- Express
- PostgreSQL
- JWT

## Project Structure
- frontend
- backend

## Goal
The goal of this project is to provide a complete restaurant platform where users can browse restaurants, make bookings, view menus, and add ratings and comments.
